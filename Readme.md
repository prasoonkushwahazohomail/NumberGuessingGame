# Number Guessing Game #
A simple Java console-based game where the player guesses a randomly generated number within a limited number of attempts.

## Features ##
- Random number generation.
- Higher and lower hints.
- Attempt counter.
- Three difficulty levels: Easy, Medium and Hard.
- Maximum attempt limits.
- Play again option.
- Score tracking across multiple rounds.

## Technology used ##
- Java
- Scanner
- Random
- IntelliJ IDEA

## How to run ##
- Clone this repo
- Open the project in IntelliJ IDEA
- Run Main.java
- Select a difficulty level and start guessing

## Difficulty Levels ##

| Level  | Number Range | Attempts |
|--------|--------------|----------|
| Easy   | 1–50         | 10       |
| Medium | 1–100        | 7        |
| Hard   | 1–200        | 5        |
